# Research release and manuscript checklist

This repository is publicly accessible. The following checks are independent
of the publication of a journal article or any additional raw-data archive.

- [x] Upload the research README, processed numerical datasets, input files, and analysis scripts.
- [x] Publish the research repository at its current GitHub URL.
- [ ] Confirm the final manuscript and its figures against the released numerical datasets.
- [ ] Finalize authors' approval of the complete public research release and its wording.
- [ ] Select explicit licenses for original code and datasets; verify the terms for redistributing `inputs/Si.sw`.
- [ ] Review any separately distributed raw numerical `.dat` archive for sensitive paths, identifiers, and unapproved files.
- [ ] Record Python, scikit-learn and scientific-software versions to improve numerical reproducibility.
- [ ] Verify that the reported INV1 means do not meet both original target limits (κ_z > 2.4 W m^-1 K^-1; E_x < 70 GPa).
- [ ] Describe the four-feature GP comparison with INV1 as retrospective and exploratory.
- [ ] Create a fixed, versioned GitHub release after final verification, if desired.
- [ ] State the public source link accurately in the manuscript's Data and Code Availability section; do not claim a paper DOI or independent raw-data archive DOI until one exists.

The publication status, licensing status, and availability of additional raw data
must be reported accurately and separately.

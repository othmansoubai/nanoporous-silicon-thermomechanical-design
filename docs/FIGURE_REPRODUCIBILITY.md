# Figure generation and reproducibility policy

Every **new public-data figure** has a named callable function in `analysis/make_public_figures.py`; run `python analysis/make_public_figures.py --only all` from any directory. Outputs are vector PDFs under `figures/`.

| Python slot | Output PDF | Numerical input | Public regeneration |
|---|---|---|---|
| `geometry()` | `fig_pass10_matched_footprints.pdf` | `data/jobs/pass7_geometry_manifest.csv` | Yes |
| `orientation_seeds()` | `fig_pass10_pass7_per_seed.pdf` | `data/processed/pass7_seed_results_all12.csv`; `pass7_summary_all4.csv` | Yes |
| `pareto22()` | `fig_pareto22_public.pdf` | `data/processed/corrected_22_measured_geometries.csv` | Yes |
| `nemd_sensitivity()` | `fig_pass10_nemd_window_sensitivity.pdf` | Existing `data/processed/thermal_runs_51_with_QC.csv` | Yes |

Other figures in the author-review manuscript use different source tiers:

* **Actual 20-bin temperature profiles** and **actual tensile stress–strain traces** were generated by `build_figures_pass10.py` from `raw_source/`, distributed only in the author-review research bundle. They are not currently rebuilt by the lightweight public checkout. Their exported figure PDFs do not replace the raw records.
* **Existing manuscript graphics** inherited from earlier revision passes are supplied as vector PDFs in the author-review bundle. Some original plot builders were created before this manifest and have not yet been normalized to a figure-by-figure, public-data-only command. Do not claim universal one-command regeneration of *all* manuscript figures until that is audited.
* Figures are MD-derived numerical visualizations or geometry schematics; none of the supplied colored footprint rectangles is an atomistic image, heat flux map, or stress field.

Recommended final-journal division (requires journal/editor approval): put approximately 9–10 narrative figures in main text (structures; pore rotation; measured Pareto; thermal profiles; model validation; elastic traces; stagger response; historical design case; prospective per-seed validation); place reduction-sensitivity details, secondary Pareto comparisons and extra diagnostic panels in supporting information. Preserve the source files and independent archive checksums with any supplementary transfer.
